# TypeScript-проєкт

Цей репозиторій створений для виконання практичних робіт з дисципліни, пов'язаної з розробкою на TypeScript.

## Структура проєкту

- `src/index.ts` — вихідний код на TypeScript
- `tsconfig.json` — конфігураційний файл TypeScript
- `dist/` — згенерований JavaScript-код після компіляції

У репозиторії використовуються дві основні гілки: `main` та `develop`. Основна розробка ведеться в гілці `develop`.
